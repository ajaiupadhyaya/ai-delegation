**Goal:** Finish the study:
- run every pre-registered robustness row of PAP §8.2 that no other plan or script produces;
- red-team every headline number and claim, with a written log;

**Architecture:** A `aideleg.robustness` package runs each row through two shared runners: one for market variants (§3.3 inference with s, b̄ and q recomputed) and one for RQ1 variants (the inference of the hypothesis varied). Each row writes `docs/results/robustness/R<nn>.{csv,md}` in one schema. A single adapter module (`robustness/upstream.py`) is the only place Plan 4 imports Plan 2 or Plan 3 code. Parity tests pin it to their committed confirmatory outputs. An `aideleg.paper` package turns every result file into Quarto variables (`docs/paper/_variables.yml`) and generated includes (`docs/paper/_generated/`). The `.qmd` prose never contains a hand-typed numeral, and a test enforces this.

**Tech Stack:** Python 3.12, uv, Polars, NumPy, SciPy, statsmodels 0.15.0, matplotlib through Plan 2's figure system, pytest, ruff, Make, Quarto 1.9 (PDF via XeLaTeX, HTML), pypdf (dev dependency, page counts).
