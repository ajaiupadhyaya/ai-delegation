Source: PAP §8.2, row R4. Label: robustness; exploratory.

Every record below is reported as robustness; not a confirmatory decision (PAP §8.1).

Units: annualised Sharpe ratio; annualised pp; correlation; pp of CAR per 1 SD; pp per month per 1 SD; pp per month per unit of log BE/ME; pp per month per unit of log size; pp per month per unit of the 12-2 return (decimal); probability. Estimates and scales are formatted to 2 decimals (correlations to 3), p to 3 decimals; the CSV keeps full precision.

## Notes

- Variant: ExposureSpec(design='A_pooled', source='1p_api'); every other construction choice is the primary A_pooled one. A_pooled is labelled look-ahead (PAP §8.3 D19).
- `1p_api` in place of `claude_ai` for A_pooled, pooled over r3–r6 with equal release weights: the API source starts at r3 (PAP §8.2 R4; §11 C-65). Design B has no API source. For RQ1 this variant is merged into R22 and R24 (PAP §8.2 R4).
- Benchmarks: AIOE and Eloundou stay at their primary values, because this occupation-level variant changes neither the matrix nor the crosswalk (PAP §11 C-65).
- Bootstrap draws: `run_terciles` consumes one `default_rng(SEED)` in `VARIANTS` order (PAP §11 C-37); with only A_pooled passed its variants draw first, so the mean and Sharpe bootstrap CIs use different draws from the primary run's A_pooled rows. A CI difference against the primary is partly draw noise, not only the exposure change.
- Zero-assigned employment share (D3): 6.89%
- RQ2 part: Spearman correlations of the variant AEI indices with the variant benchmarks; the intervals are 2.5/97.5 percentile industry-bootstrap intervals on Plan 2's Design B draw set `bootstrap_indices(n)["B"]` (PAP §11 C-68). RQ2 is descriptive.
- Index part: the Spearman correlation of the variant A_pooled `z_delegation` with the primary A_pooled `z_delegation` (Plan 3's `data.exposures()`), across the FF49 industries with both values; descriptive.
- Design A parts run Plan 3's own runners on the exposure frame passed: `run_terciles` (fixed-membership H-L terciles, cap and EW legs; C-34, C-35, C-37, C-45), `run_fm` (Fama–MacBeth on [1, z, log size, log BE/ME, 12-2 momentum]; C-38, C-46) and `run_events` (the 14 D19 events, CAR slopes at horizons 5 and 20, HC3 normal reference; C-33, C-44). Records are read from the frames the runners return; their docs are written under the untracked `data/derived/robustness/<row>/<part>` and no figure is written.
- Columns: estimate, interval and p are as Plan 3 returns them; the scale column holds the SE (Newey-West for terciles and Fama–MacBeth, HC3 for event slopes); n is T (months) for terciles and Fama–MacBeth and the number of industries for event slopes. Null 0, nominal and single-test; no error control across records or rows (PAP §8.1). Sharpe, PSR and DSR carry no p; PSR and DSR carry no interval.
- DSR here is against the 2 tercile variants run in this row (the primary used 6, C-37); not comparable with the primary's DSR (PAP §11 C-76).
