# R28: robustness row (PAP §8.2 R28)

Source: PAP §8.2, row R28. Label: robustness.

Every record below is reported as robustness; not a confirmatory decision (PAP §8.1).

Units: pp of the outcome share per unit of the regressor. Estimates and scales are formatted to 2 decimals (correlations to 3), p to 3 decimals; the CSV keeps full precision.

## Notes

- H4 alternatives (PAP §4.4 D16, §8.2 R28), each part ending in Plan 2's `estimate_h4` (through the adapter) with H4's inference (PAP §8.1): OLS of the geography's overall automation_pct on [1, log AUI, log income, mix] with HC3 covariance (WLS in usage_weighted); b₁ (log AUI) and b₂ (log income) carry normal-reference HC3 95% intervals and two-sided p; p_wald (joint Wald) is the joint HC3 Wald F test of b₁ = b₂ = 0 with (2, n − 4) df (D17), whose `stat` is F. Coefficients are in pp of the automation share per unit of the log regressor. Each table row's note cell starts with its coefficient (PAP §11 C-78). `n` is the number of geographies in the fit; `n_dropped` is the number excluded and `dropped` the count by first failing reason, in Plan 2's order (missing_month, missing_income, missing_mix); the excluded geographies are listed below. Reported only, not a decision: the H4 decision is P-RQ1's.
- us_states: r6 `claude_ai` subregions whose `geo_id` starts `US-`, by Plan 2's `build_geo_sample(geo="us_state")`: the published state `usage_per_capita_index`, 2024 state GDP per working-age person from the AEI r3 state files, and the GWA mix.
- [default] r4_countries, r5_countries: Plan 4's `h4_frame_r45` (PAP §11 C-59), because r4 and r5 publish no country usage index and no country GWA rows. log AUI = ln(usage_pct_c / working-age population_c); AEI's index is the usage share over the working-age population share, so the common scale moves only the intercept. s_cg is the country's `onet_task` pct aggregated to GWAs through the D14 files (`task_families("gwa")`), each task split equally over its GWAs, then renormalised over the GWAs with an ā_g. ā_g is the same release's global task `automation_pct` aggregated to GWA with D13 weights (the task's global pct, split equally over its GWAs). Income is 2024 GDP per working-age person (D16, the r3 inputs Plan 2 uses). Each release has one published period, so nothing is averaged over months. Inclusion as D16: overall automation_pct and usage_pct published, income, and a mix.
- [default] In r4_countries and r5_countries a task's GWAs are the union over its candidate Task IDs (its panel Task ID and every Task ID carrying its statement), as Plan 2's H1/H3 task rows apply D14 (PAP §11 C-9, C-59); unmatched task nodes and tasks with no DWA link carry no GWA.
- In r4_countries and r5_countries the excluded geographies listed below include AEI's non-country buckets (`unmatched:*`), which are counted in `n_dropped` and `dropped` with the countries.
- usage_weighted: the D16 r6 country frame, estimated by WLS with weights = the country's two-month mean overall `usage_pct` (PAP §4.4 'weights = country usage_pct'); the sample is the primary one.
- iwa_mix: the D16 r6 country sample with the task-mix control built over IWA (`onet_iwa`) nodes in place of GWAs, by Plan 2's builder (`mix_level="iwa"`), with the same formula (PAP §4.4 'IWA-level mix control where published').
- The mix control (Plan 2's, and Plan 4's r4/r5 mix built the same way) sums over an unordered group_by, so mix and the estimates reproduce only to about 1e-14 between runs (PAP §11 C-32), far below the printed precision.
- us_states: excluded missing_month 1 (US-PR)
