# R35: robustness row (PAP §8.2 R35)

Source: PAP §8.2, row R35. Label: robustness.

Every record below is reported as robustness; not a confirmatory decision (PAP §8.1).

Units: pp of annualised alpha per 1 SD. Estimates and scales are formatted to 2 decimals (correlations to 3), p to 3 decimals; the CSV keeps full precision.

## Notes

- Studentised statistic (PAP §8.2 R35, P10): for each of the 378 pre-seal windows w, Σ_w is the covariance of the industries' daily FF5+UMD residuals (denominator T_w − 7), c_w = [(X_w′X_w)⁻¹]₁₁ is the intercept element of the common factor design, ω the OLS weight vector with b = ω′α ([1, z] for H5, [1, z, z_aioe] for H5b), SE_Σ,w = 252·√(c_w·ω′Σ_wω), and κ = sd_w(b_w)/median_w(SE_Σ,w), the same sd as s.
- In the confirmatory window SE_Σ is computed the same way; stat = T_stud = (b̂ − b₀)/(κ·SE_Σ) with b₀ = b̄ (D21), p from t₂₁, and the t₂₁ criticals of §3.3. The scale column is κ·SE_Σ in pp and the interval is b̂ ± t₂₁,0.975·κ·SE_Σ (the §3.3 interval form with this scale).
- Exposure: the primary Design B vector (`ExposureSpec()`). H5 and H5b with s, b̄ and q recomputed for this row by the pre-seal procedure (the same 378 windows unless the row says otherwise, the t₂₁ rule and the D21 null b₀ = b̄; PAP §3.3, §8.1); industries with a missing return in the confirmatory window are dropped and z is not re-standardised. The secondary b = 0 statistic is in each record's note.
- Zero-assigned employment share (D3): 12.14% (the primary Design B exposure; this row rebuilds no index).
