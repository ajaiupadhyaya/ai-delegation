- Exposure: Plan 3's primary A_r2 and A_pooled `z_delegation` (A_pooled labelled look-ahead, PAP §8.3 D19); this row rebuilds no index.

- Columns: estimate, interval and p are as Plan 3 returns them; the scale column holds the SE (Newey-West for terciles and Fama–MacBeth, HC3 for event slopes); n is T (months) for terciles and Fama–MacBeth and the number of industries for event slopes.
