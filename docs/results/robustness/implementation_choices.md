## Reproduction of the row files

- §11 C-80 (Reproduction tolerance for robustness CSVs): a re-run must reproduce every row `.md` byte for byte; a regenerated CSV reproduces the committed one when every non-numeric cell is identical and every numeric cell agrees within relative 1e-9 (absolute 1e-12 near zero), and the committed bytes are then kept (`reproduce.csv_equivalent`, used by `report.write_row`). The last float digits of R15, R28 and R29 move from run to run (summation order); no printed number moves.
