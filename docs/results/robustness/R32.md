# R32: robustness row (PAP §8.2 R32)

Source: PAP §8.2, row R32. Label: robustness.

Every record below is reported as robustness; not a confirmatory decision (PAP §8.1).

Units: pp of annualised alpha per 1 SD. Estimates and scales are formatted to 2 decimals (correlations to 3), p to 3 decimals; the CSV keeps full precision.

## Notes

- Variant market: ExposureSpec(oews_year=2023, onet='29.2') on ff49_vw (49 industries); every other construction choice is the primary Design B one.
- Strict real-time Design B (PAP §8.2 R32, P15): release r2 with OEWS May 2023 weights (oesm23in4, oesm23nat) and O*NET task statements ≤ 29.2, i.e. inputs public at 2025-03-27; s, b̄ and q recomputed.
- The O*NET 29.2 Task Statements file is byte-identical to the 29.3 file of the primary, so R32's task index equals the primary's and R32 differs from the primary only through the OEWS May 2023 weights (PAP §11 C-74).
- Benchmarks: AIOE and Eloundou are re-aggregated with the variant's matrix, crosswalk and industry set, so both sides of H5b use the same weights (PAP §11 C-65).
- market: Zero-assigned employment share (D3): 12.19%
- Market parts: H5 and H5b on each part's return set with s, b̄ and q recomputed for the part's exposure vector on the same 378 pre-seal windows with the same code, the critical max(t₂₁, q) and the D21 null b₀ = b̄ (PAP §3.3, §8.1); industries with a missing return in the confirmatory window are dropped and z is not re-standardised after a drop. The secondary b = 0 statistic is in each record's note.
